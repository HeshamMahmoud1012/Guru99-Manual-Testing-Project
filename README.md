# Guru99 Bank - Manual Testing Project

End-to-end manual testing of the Guru99 Bank demo web application, completed as part of the DigiLians Software Testing training (MCIT, Feb-Jun 2026).

## Scope

Full functional testing of the Guru99 Bank application across Manager and Customer roles:

- Customer management: New, Edit, Delete Customer
- Account management: New, Edit, Delete Account
- Transactions: Deposit, Withdrawal, Fund Transfer
- Statements: Balance Enquiry, Mini Statement, Customized Statement
- Security: Login/Logout, Change Password

## Deliverables

[Guru99-Bank-Test-Suite.xlsx](https://github.com/HeshamMahmoud1012/Guru99-Manual-Testing-Project/releases/download/v1.0/Guru99-Bank-Test-Suite.xlsx) (download from release v1.0) - the complete test suite, one tab per module:

- Test plan with module ownership and execution status
- Detailed test cases: preconditions, steps, test data, expected vs actual results, pass/fail status
- Bug reports with severity and priority classification

Testing types covered: Functional, Regression, Smoke, and Exploratory Testing.

## Team Project Note

This was a team training project. Modules I designed and executed personally: **New Account, Deposit, Balance Enquiry (Manager), and Change Password (Customer)**. Other modules were owned by teammates and are kept in the workbook for completeness.

## Tools

Test design and documentation in spreadsheets; defect tracking concepts aligned with JIRA workflows; Agile (Scrum) team collaboration.
